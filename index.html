E.01NETWORK

The first request is the loudest.

To deliver a page, a server sees the connecting IP. An IP lookup adds approximate city, region, country, ISP and ASN. That is network-level information, not GPS — but it is enough to narrow the crowd before a single script runs.

Sourceipwho.is documentation
E.02FINGERPRINT

No permission is required to render.

Canvas, WebGL and installed font probing work inside the normal page sandbox. The resulting differences can be stable enough to compare visits, which is why the technique is called fingerprinting.

SourceEFF Cover Your Tracks
E.03BATTERY

Battery was once an open book.

The Battery Status API exposed level and charging state. Availability is limited and varies by browser and platform; this audit reports it only when the API answers, and marks it unavailable otherwise.

SourceMDN Battery Status API
E.04CONSENT

Permission state is per origin.

A granted camera permission here says nothing about another site. The Permissions API can reveal whether access is granted, denied or promptable — but not all features are queryable everywhere. This page queries status only, never access.

SourceMDN Permissions API
E.05NETWORK INFO

Network hints are optional.

The Network Information API, where implemented, may expose effective connection type, estimated downlink and RTT. It does not reveal the Wi-Fi SSID, carrier account or router. Browser support is uneven, so the ledger treats absence as a result.

SourceMDN Network Information API
E.06LIMITS

A silhouette is not a name — until it is connected.

Fingerprints are imperfect and can change after updates, zoom changes, new fonts or privacy tools. They become more identifying when a network sees them repeatedly, sets cookies, or joins them to a login. The honest conclusion is not “they know everything.” It is “they know enough to compare.”

SourceMDN User-Agent Client Hints

How this mirror works.

READ ME FIRST

WhatTheySee is a static page. It has no backend, no account system, no analytics and no way to receive your scan. Its only outbound traffic is an IP lookup — primary provider, plus a fallback only if the first fails — so it can show the approximate network location that any server would already see.

WHAT WE DID
  • 01
    Read browser APIs

    Device, display, language, time, capabilities, permissions status, battery where available.

  • 02
    Made one IP lookup

    Sent a normal HTTPS request to an independent IP geolocation service. That service saw your IP, as any web server must.

  • 03
    Built a local signature

    Hashed selected values with SHA-256 inside this tab. The resulting hash was not transmitted.

WHAT WE NEVER DID
  • Request geolocation, camera, microphone or clipboard
  • Set a tracking cookie or read third-party cookies
  • Store your scan in localStorage or a database
  • Load analytics, ads, CDN scripts, maps or remote fonts
  • Send your fingerprint, screen or battery values anywhere

HOW THE INDEX IS BUILT

The exposure index is a weighted count of signal availability across eight groups — network, precision, device, display, context, fingerprint, battery and surface. The weights sum to 100; fingerprint carries the largest single weight because it is the most reusable comparison surface. This is not a measure of danger, and it is not benchmarked against other people. It answers one narrow question: how much of the page’s passive instrument had something to read? The fix projection is a deliberately simple model that subtracts a fixed weight for each completed action.

ACCURACY

IP geolocation is approximate and can be wrong. User-agent strings can be spoofed. Signatures change. Battery and network APIs vary by browser. Treat every value as a clue, not a fact.

STORAGE

Theme preference and the fix checklist may be saved in localStorage so they survive reloads. Scan values are held in memory only and disappear when the tab closes.

PROVIDERS

IP lookup: ipwho.is primary; ipapi.co fallback, attempted only if the primary fails. Basemap: Natural Earth (public domain). Sources are linked in the evidence section. Self-hosted fonts; no remote assets.
